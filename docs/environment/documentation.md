# Documentation

The documentation is written using Markdown and published with `MkDocs`. All
these documents are under the `docs` folder, and the structure and
configuration of the site are under the `mkdocs.yml` file.

You can test the documentation site by running `mkdocs serve`. To access this
site, open a browser at the URL: [http://localhost:8000](http://localhost:8000)

```bash
mkdocs serve
```
